# Locus Club

Plataforma de mentoria para donos de negócio.

## Stack

- React, Vite, TypeScript, Tailwind CSS
- TanStack Router
- API Node.js (Express + Knex + MySQL)

## Desenvolvimento

Requer Node.js e npm.

```sh
npm i
npm run dev
```

API:

```sh
cd api
npm i
npm run dev
```

Build do frontend:

```sh
npm run build
```
